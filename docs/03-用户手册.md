## 登录与认证

### 首次登录

1. 访问系统地址（如 http://localhost:3000）
2. 输入默认账号：
   - 用户名: `admin`
   - 密码: `admin123`
3. 点击"登录"按钮

### 修改密码

登录后建议立即修改密码：

1. 点击右上角用户名
2. 选择"修改密码"
3. 输入当前密码和新密码
4. 点击"确认"

### 忘记密码

联系系统管理员重置密码。

## 设备管理

### 添加设备

1. 进入"设备管理"页面
2. 点击右上角"添加设备"按钮
3. 填写设备信息：
   - **设备名称**: 设备的友好名称（如：核心交换机-01）
   - **IP地址**: 设备的 IP 地址
   - **SSH端口**: SSH 连接端口（默认 22）
   - **用户名**: 登录用户名（如：admin）
   - **密码**: 登录密码
   - **设备类型**: 选择设备类型（交换机/路由器/防火墙）
   - **描述**: 设备描述信息（可选）
4. 点击"测试连接"验证连接
5. 连接成功后点击"保存"

### 设备列表

设备列表显示所有已添加的设备，包括：
- 设备名称
- IP 地址
- 设备类型
- 连接状态（在线/离线）
- 最后连接时间
- 操作按钮

### 设备操作

#### 连接/断开
- 点击"连接"按钮建立与设备的连接
- 点击"断开"按钮断开与设备的连接

#### 编辑设备
1. 点击设备行的"编辑"按钮
2. 修改设备信息
3. 点击"保存"

#### 删除设备
1. 点击设备行的"删除"按钮
2. 确认删除操作
3. 注意：删除设备会同时删除该设备的所有配置

#### 查看详情
点击设备名称可查看设备详细信息，包括：
- 设备基本信息
- 设备系统信息
- 接口列表
- 路由表
- 运行配置

### 设备搜索

在搜索框中输入设备名称或 IP 地址进行快速搜索。

## 配置管理

### 创建配置

1. 进入"配置管理"页面
2. 在左侧选择要配置的设备
3. 点击"添加配置"按钮
4. 填写配置信息：
   - **配置名称**: 配置的友好名称
   - **配置类型**: 选择配置类型（接口配置/路由配置/VLAN配置/ACL配置）
   - **配置内容**: 输入配置命令（华为设备命令格式）
   - **描述**: 配置描述（可选）
5. 点击"保存"

示例配置内容：
```
interface GigabitEthernet0/0/1
 description Uplink to Core
 port link-type trunk
 port trunk allow-pass vlan 10,20,30
```

### 配置列表

配置列表显示选中设备的所有配置，包括：
- 配置名称
- 配置类型
- 创建时间
- 状态（草稿/已激活/已部署）
- 操作按钮

### 配置操作

#### 激活配置
1. 点击配置行的"激活"按钮
2. 确认激活操作
3. 配置将被标记为"已激活"状态

#### 部署配置
1. 点击配置行的"部署"按钮
2. 确认部署操作
3. 系统将配置推送到设备
4. 查看部署结果

#### 编辑配置
1. 点击配置行的"编辑"按钮
2. 修改配置内容
3. 点击"保存"

#### 删除配置
1. 点击配置行的"删除"按钮
2. 确认删除操作

### 配置模板

系统提供常用配置模板：
- 接口配置模板
- VLAN 配置模板
- 路由配置模板
- ACL 配置模板

选择模板后可快速创建配置。

## 告警管理

### 告警列表

告警列表显示所有告警，包括：
- 告警级别（严重/警告/信息）
- 告警时间
- 告警设备
- 告警类型
- 告警内容
- 处理状态（未处理/已处理）

### 告警筛选

可按以下条件筛选告警：
- **告警级别**: 选择严重/警告/信息
- **处理状态**: 选择未处理/已处理
- **设备**: 选择特定设备
- **时间范围**: 选择时间范围

### 告警操作

#### 查看详情
点击告警行可查看告警详细信息，包括：
- 告警完整信息
- 相关设备信息
- 历史处理记录

#### 处理告警
1. 点击告警行的"处理"按钮
2. 输入处理说明
3. 点击"确认"
4. 告警状态更新为"已处理"

#### 批量处理
1. 勾选多个告警
2. 点击"批量处理"按钮
3. 输入处理说明
4. 点击"确认"

### 告警通知

当产生告警时，系统会通过以下方式通知：
- 企业微信（如已配置）
- 短信（如已配置）
- 邮件（如已配置）

## 网络优化

### 优化状态

优化页面显示当前优化状态：
- **自动优化**: 是否启用自动优化
- **上次优化时间**: 上次执行优化的时间
- **优化结果**: 上次优化的结果

### 手动优化

#### 路由优化
1. 点击"路由优化"按钮
2. 系统分析当前路由配置
3. 提供优化建议
4. 确认后应用优化

#### 带宽管理
1. 点击"带宽管理"按钮
2. 系统分析带宽使用情况
3. 提供带宽优化建议
4. 确认后应用优化

#### 负载均衡
1. 点击"负载均衡"按钮
2. 系统分析流量分布
3. 提供负载均衡建议
4. 确认后应用优化

### 优化日志

优化日志记录所有优化操作，包括：
- 优化时间
- 优化类型
- 优化设备
- 优化内容
- 优化结果

### 自动优化配置

在配置文件中启用自动优化：

```yaml
auto_optimization:
  enabled: true
  check_interval: 300  # 5分钟检查一次
  enable_route_optimization: true
  enable_bandwidth_management: true
  enable_load_balancing: true
```

## 常见问题

### Q: 如何批量添加设备？
A: 目前系统不支持批量导入，需要逐个添加设备。未来版本将支持 CSV 导入功能。

### Q: 配置部署失败怎么办？
A: 检查以下几点：
1. 设备是否在线
2. 设备凭据是否正确
3. 配置命令是否正确
4. 查看系统日志获取详细错误信息

### Q: 如何修改监控阈值？
A: 编辑 `config/config.yaml` 文件中的 `monitoring` 部分，修改相应阈值后重启服务。

### Q: 告警通知不生效？
A: 检查以下几点：
1. 通知服务配置是否正确
2. API 密钥是否有效
3. 网络是否可以访问通知服务
4. 查看后端日志获取详细错误信息

### Q: 如何备份数据？
A: 参考生产环境部署指南中的数据备份章节。

### Q: 系统支持哪些华为设备？
A: 系统支持通过 SSH 管理的华为交换机、路由器和防火墙设备。建议使用华为 VRP 平台设备。
