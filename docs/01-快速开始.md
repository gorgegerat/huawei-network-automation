# 快速开始指南

## 环境要求

### 最低要求
- **操作系统**: Windows 10/11, Linux (Ubuntu 20.04+), macOS 10.15+
- **Docker**: 20.10+
- **Docker Compose**: 2.0+
- **内存**: 至少 4GB RAM
- **磁盘空间**: 至少 10GB 可用空间

### 可选（本地开发）
- **Python**: 3.9+
- **Node.js**: 18+

## 一键部署

### Windows 环境

1. **下载项目**
   ```bash
   cd d:/网络部署运维自动化
   ```

2. **运行部署脚本**
   - 双击 `deploy.bat`（推荐）
   - 或在 PowerShell 中运行 `deploy.ps1`

3. **等待部署完成**
   - 脚本会自动检查 Docker 环境
   - 创建必要的目录
   - 构建所有 Docker 镜像
   - 启动所有服务

4. **访问系统**
   - 前端界面: http://localhost:3000
   - 后端 API: http://localhost:8000
   - API 文档: http://localhost:8000/docs

### Linux/macOS 环境

1. **下载项目**
   ```bash
   cd /path/to/network-auto
   ```

2. **配置环境变量**
   ```bash
   cp .env.example .env
   # 编辑 .env 文件，填入您的配置
   ```

3. **启动服务**
   ```bash
   docker-compose up -d
   ```

4. **访问系统**
   - 前端界面: http://localhost:3000
   - 后端 API: http://localhost:8000
   - API 文档: http://localhost:8000/docs

## 初始配置

### 1. 配置通知服务

编辑 `config/config.yaml` 或 `.env` 文件：

#### 企业微信配置
```yaml
notifications:
  wechat:
    enabled: true
    corp_id: "your-corp-id"        # 企业ID
    agent_id: "your-agent-id"      # 应用ID
    secret: "your-secret"          # 应用密钥
```

#### 阿里云短信配置
```yaml
notifications:
  sms:
    enabled: true
    access_key_id: "your-access-key-id"
    access_key_secret: "your-access-key-secret"
    sign_name: "网络运维"
    template_code: "SMS_123456789"
```

#### 邮件配置
```yaml
notifications:
  email:
    enabled: true
    smtp_server: "smtp.example.com"
    smtp_port: 587
    smtp_username: "noreply@example.com"
    smtp_password: "your-password"
    from_address: "noreply@example.com"
    to_addresses:
      - "admin@example.com"
      - "ops@example.com"
```

### 2. 配置华为设备凭据

```yaml
huawei:
  default_username: "admin"
  default_password: "Admin@123"
  ssh_port: 22
  connection_timeout: 30
  command_timeout: 60
```

### 3. 配置监控阈值

```yaml
monitoring:
  check_interval: 60              # 检查间隔（秒）
  cpu_threshold: 80               # CPU使用率阈值(%)
  memory_threshold: 85            # 内存使用率阈值(%)
  bandwidth_threshold: 90         # 带宽使用率阈值(%)
  latency_threshold: 100          # 延迟阈值(ms)
  packet_loss_threshold: 1        # 丢包率阈值(%)
```

## 首次登录

1. 打开浏览器访问 http://localhost:3000
2. 使用默认账号登录：
   - 用户名: `admin`
   - 密码: `admin123`
3. 登录后请立即修改密码

## 添加设备

1. 进入"设备管理"页面
2. 点击"添加设备"按钮
3. 填写设备信息：
   - 设备名称
   - IP地址
   - SSH端口（默认22）
   - 用户名
   - 密码
   - 设备类型（交换机/路由器/防火墙）
4. 点击"连接"测试连接
5. 连接成功后点击"保存"

## 常用命令

### 查看服务状态
```bash
docker-compose ps
```

### 查看日志
```bash
# 查看所有服务日志
docker-compose logs -f

# 查看特定服务日志
docker-compose logs -f backend
docker-compose logs -f frontend
docker-compose logs -f agent
```

### 停止服务
```bash
docker-compose down
```

### 重启服务
```bash
docker-compose restart
```

### 重新构建
```bash
docker-compose up -d --build
```

### 清理数据（谨慎使用）
```bash
docker-compose down -v
rm -rf data logs
```

## 故障排查

### 服务无法启动

1. 检查 Docker 是否正常运行
   ```bash
   docker --version
   docker-compose --version
   ```

2. 检查端口是否被占用
   ```bash
   # Windows
   netstat -ano | findstr :3000
   netstat -ano | findstr :8000

   # Linux/macOS
   lsof -i :3000
   lsof -i :8000
   ```

3. 查看服务日志
   ```bash
   docker-compose logs
   ```

### 无法连接设备

1. 检查设备 IP 地址是否正确
2. 检查 SSH 端口是否开放
3. 检查用户名和密码是否正确
4. 检查网络连通性
   ```bash
   ping <设备IP>
   telnet <设备IP> 22
   ```

### 通知不生效

1. 检查配置文件中的 API 密钥是否正确
2. 检查网络是否可以访问通知服务
3. 查看后端日志中的错误信息

## 生产环境部署

生产环境建议使用 `docker-compose.prod.yml`：

```bash
docker-compose -f docker-compose.prod.yml up -d
```

生产环境配置：
- 前端使用 80 端口
- 后端使用 4 个 worker 进程
- 启用健康检查
- 配置文件只读挂载

详细配置请参考 [生产环境部署指南](./02-生产环境部署.md)
