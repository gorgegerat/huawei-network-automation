# 生产环境部署指南

## 系统要求

### 服务器配置
- **CPU**: 4 核心或以上
- **内存**: 8GB 或以上
- **磁盘**: 50GB SSD 或以上
- **网络**: 千兆网卡或以上
- **操作系统**: Ubuntu 20.04 LTS / CentOS 8+ / Debian 11+

### 软件要求
- **Docker**: 20.10+
- **Docker Compose**: 2.0+
- **Nginx** (可选，用于反向代理)
- **SSL 证书** (推荐，用于 HTTPS)

## 部署前准备

### 1. 安全配置

#### 修改默认密码
```bash
# 生成强密码
openssl rand -base64 32
```

更新 `.env` 文件：
```env
SECRET_KEY=<生成的强密钥>
JWT_SECRET=<生成的JWT密钥>
```

#### 配置防火墙
```bash
# Ubuntu/Debian
ufw allow 80/tcp
ufw allow 443/tcp
ufw allow 22/tcp
ufw enable

# CentOS/RHEL
firewall-cmd --permanent --add-service=http
firewall-cmd --permanent --add-service=https
firewall-cmd --permanent --add-service=ssh
firewall-cmd --reload
```

### 2. SSL 证书配置

#### 使用 Let's Encrypt (推荐)
```bash
# 安装 certbot
sudo apt-get install certbot

# 生成证书
sudo certbot certonly --standalone -d your-domain.com

# 证书路径
# /etc/letsencrypt/live/your-domain.com/fullchain.pem
# /etc/letsencrypt/live/your-domain.com/privkey.pem
```

#### 使用自签名证书（测试用）
```bash
openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout /etc/nginx/ssl/nginx.key \
  -out /etc/nginx/ssl/nginx.crt
```

### 3. 数据库配置

生产环境建议使用 PostgreSQL 或 MySQL：

#### PostgreSQL 配置
```env
DATABASE_URL=postgresql://user:password@localhost:5432/network
```

#### MySQL 配置
```env
DATABASE_URL=mysql://user:password@localhost:3306/network
```

## 部署步骤

### 1. 上传代码到服务器

```bash
# 使用 Git
git clone <repository-url> /opt/network-auto
cd /opt/network-auto

# 或使用 SCP
scp -r network-auto user@server:/opt/
```

### 2. 配置环境变量

```bash
cp .env.example .env
nano .env
```

关键配置项：
```env
# 数据库
DATABASE_URL=postgresql://user:password@localhost:5432/network

# 安全密钥（必须修改）
SECRET_KEY=<强密钥>
JWT_SECRET=<JWT密钥>

# 通知服务配置
WECHAT_CORP_ID=<企业微信CorpID>
WECHAT_AGENT_ID=<企业微信AgentID>
WECHAT_SECRET=<企业微信Secret>

SMS_ACCESS_KEY_ID=<阿里云AccessKey>
SMS_ACCESS_KEY_SECRET=<阿里云AccessSecret>

SMTP_SERVER=smtp.example.com
SMTP_PORT=587
SMTP_USERNAME=noreply@example.com
SMTP_PASSWORD=<邮箱密码>
```

### 3. 配置 Nginx 反向代理

创建 Nginx 配置文件 `/etc/nginx/sites-available/network-auto`：

```nginx
upstream backend {
    server localhost:8000;
}

upstream frontend {
    server localhost:3000;
}

server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name your-domain.com;

    ssl_certificate /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;

    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;

    # 前端
    location / {
        proxy_pass http://frontend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 后端 API
    location /api {
        proxy_pass http://backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # WebSocket 支持
    location /ws {
        proxy_pass http://backend;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

启用配置：
```bash
sudo ln -s /etc/nginx/sites-available/network-auto /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### 4. 启动服务

```bash
# 使用生产环境配置
docker-compose -f docker-compose.prod.yml up -d

# 查看服务状态
docker-compose -f docker-compose.prod.yml ps

# 查看日志
docker-compose -f docker-compose.prod.yml logs -f
```

### 5. 配置自动重启

编辑 `/etc/systemd/system/docker-compose.service`：

```ini
[Unit]
Description=Docker Compose Application Service
Requires=docker.service
After=docker.service

[Service]
Type=oneshot
RemainAfterExit=yes
WorkingDirectory=/opt/network-auto
ExecStart=/usr/local/bin/docker-compose -f docker-compose.prod.yml up -d
ExecStop=/usr/local/bin/docker-compose -f docker-compose.prod.yml down
TimeoutStartSec=0

[Install]
WantedBy=multi-user.target
```

启用服务：
```bash
sudo systemctl enable docker-compose.service
sudo systemctl start docker-compose.service
```

## 监控和维护

### 1. 日志管理

配置日志轮转 `/etc/logrotate.d/network-auto`：

```
/opt/network-auto/logs/*.log {
    daily
    rotate 30
    compress
    delaycompress
    missingok
    notifempty
    create 0640 www-data www-data
    sharedscripts
    postrotate
        docker-compose -f /opt/network-auto/docker-compose.prod.yml restart agent
    endscript
}
```

### 2. 数据备份

创建备份脚本 `/opt/backups/network-auto-backup.sh`：

```bash
#!/bin/bash
BACKUP_DIR="/opt/backups/network-auto"
DATE=$(date +%Y%m%d_%H%M%S)
mkdir -p $BACKUP_DIR

# 备份数据库
docker exec network-auto-backend-prod sqlite3 /app/data/network.db ".backup /tmp/backup.db"
docker cp network-auto-backend-prod:/tmp/backup.db $BACKUP_DIR/network_$DATE.db

# 备份配置
tar -czf $BACKUP_DIR/config_$DATE.tar.gz /opt/network-auto/config

# 删除30天前的备份
find $BACKUP_DIR -type f -mtime +30 -delete
```

设置定时任务：
```bash
crontab -e
# 每天凌晨2点备份
0 2 * * * /opt/backups/network-auto-backup.sh
```

### 3. 性能监控

使用 Prometheus + Grafana 监控：

```yaml
# docker-compose.monitoring.yml
version: '3.8'

services:
  prometheus:
    image: prom/prometheus
    ports:
      - "9090:9090"
    volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml

  grafana:
    image: grafana/grafana
    ports:
      - "3001:3000"
    environment:
      - GF_SECURITY_ADMIN_PASSWORD=admin
```

### 4. 健康检查

创建健康检查脚本 `/opt/health-check.sh`：

```bash
#!/bin/bash
# 检查后端健康
curl -f http://localhost:8000/health || exit 1

# 检查前端
curl -f http://localhost:3000 || exit 1

# 检查数据库连接
docker exec network-auto-backend-prod python -c "from database import engine; engine.connect()" || exit 1

echo "All services are healthy"
```

## 高可用配置

### 1. 负载均衡

使用 HAProxy 或 Nginx 进行负载均衡：

```nginx
upstream backend {
    least_conn;
    server backend1:8000;
    server backend2:8000;
    server backend3:8000;
}
```

### 2. 数据库主从复制

配置 PostgreSQL 主从复制或 MySQL 主从复制。

### 3. Redis 缓存

添加 Redis 服务到 docker-compose：

```yaml
redis:
  image: redis:alpine
  ports:
    - "6379:6379"
  volumes:
    - redis_data:/data
```

## 安全加固

### 1. 限制容器权限

在 `docker-compose.prod.yml` 中：
```yaml
services:
  backend:
    security_opt:
      - no-new-privileges:true
    read_only: true
    tmpfs:
      - /tmp
```

### 2. 网络隔离

```yaml
networks:
  frontend:
    driver: bridge
  backend:
    driver: bridge
    internal: true
```

### 3. 定期更新

```bash
# 更新镜像
docker-compose -f docker-compose.prod.yml pull
docker-compose -f docker-compose.prod.yml up -d
```

## 故障恢复

### 数据库恢复

```bash
# 停止服务
docker-compose -f docker-compose.prod.yml down

# 恢复数据库
docker cp /opt/backups/network-auto/network_20240101_020000.db \
  network-auto-backend-prod:/app/data/network.db

# 启动服务
docker-compose -f docker-compose.prod.yml up -d
```

### 服务回滚

```bash
# 查看镜像历史
docker images | grep network-auto

# 回滚到指定版本
docker tag network-auto-backend:old network-auto-backend:latest
docker-compose -f docker-compose.prod.yml up -d
```
